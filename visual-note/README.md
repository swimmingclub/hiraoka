# むすびノート(試作)

AIへの質問と答えを、カード・矢印・シミュレーターとして1枚のキャンバスに並べる、学校向けノートの試作です。

- `index.html` をブラウザで開くと動きます(ビルド不要)。
- 単体で開いた場合はデモ表示になり、AIの答えは見本データです。ノートはそのブラウザ内にだけ保存されます。
- Claude のアーティファクトとして公開すると、実際の Claude が答え、ノートは共有され、他の人のカーソルが見えます。

## できること

- 1〜3個のAIに同時に質問し、答えをカードとして自動配置
  - メモ / てじゅん / 棒グラフ・折れ線グラフ / ひょう / クイズ
  - シミュレーター(つまみで数値が変わる) / うごくシミュレーター(物が動く)
  - アニメーション(めぐる図) / スライド動画(紙芝居)
- どのカードも「大きく見る」で画面いっぱいに拡大
- カードをえらんでから質問すると、そのカードについての追加の質問になり、矢印でつながる
- 実行中のAIを「とめる」、消したカードを「もどす」
- カードの移動、矢印でつなぐ、メモを置く、消す
- キャンバスの移動と拡大縮小(ドラッグ、ピンチ、Ctrl+ホイール)
